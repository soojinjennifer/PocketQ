# 참고자료: 2028학년도 대학수학능력시험 예시문항 (수학)

이 문서는 `source.json`(임포터가 읽는 구조화 데이터)과 동일한 내용을 사람이 읽기 쉬운
산문으로 정리한 것이다. 두 파일의 내용이 어긋나면 `source.json`을 기준으로 한다.

## 출처

- 발행 주체: 교육부·한국교육과정평가원(공식 기관)
- 공식 공개일: 2025-04-15
- 문서: `2028학년도 수능 예시문항 문제지ㆍ정답표 - 수학.pdf`(13페이지 — 문제지 12페이지 +
  정답표 1페이지, 30개 문항: 1~21번 5지선다형, 22~30번 단답형)
- `sourceUrl`: `https://www.kyeongin.com/article/1736305`("교육부, 2028학년도 대학수학능력시험
  예시 문항 문제지 안내" 기사). 이 PDF 실물은 해당 기사에 첨부된 네이버 정적 파일 서버
  (files-scs.pstatic.net)의 보도자료 원문 첨부본이며, 다운로드 직후 1페이지 텍스트에
  "한국교육과정평가원 [부록] 2028학년도 수능 예시문항 문제지ㆍ정답표"가 그대로 포함돼 있어
  원문임을 확인했다. 원저작권자는 경인일보가 아니라 교육부·한국교육과정평가원이다(공식
  도메인: www.moe.go.kr, www.kice.re.kr, www.suneung.re.kr).

## 교육과정 범위

- 교육과정 버전: 2022 개정(2028학년도 수능부터 처음 적용되는 새 체제)
- 다루는 과목: 대수(`ALG`), 미적분Ⅰ(`CALC1`). 문제지에는 확률과 통계 문항도 포함되어 있으나
  PocketQ 범위 밖(`OUT_OF_CURRENT_SCOPE`)이라 대수/미적분Ⅰ family에 억지로 매핑하지 않는다.

## 문항 과목 분류(직접 재확인 완료)

30개 문항을 직접 PDF로 열람해 문항 내용을 확인하고 분류했다(plan-agent의 사전 추정을
재검증):

- 대수(`ALG`) 11개: 1, 4, 7, 10, 14, 16, 19, 22, 24, 27, 30
- 미적분Ⅰ(`CALC1`) 11개: 2, 5, 8, 11, 15, 17, 18, 20, 23, 25, 28
- 확률과 통계, PocketQ 범위 밖(`OUT_OF_CURRENT_SCOPE`) 8개: 3, 6, 9, 12, 13, 21, 26, 29

## 라이선스 상태

- 관찰된 라이선스 표시: 없음(공식 기관 배포 자료에 별도 재배포 라이선스 명시 없음)
- 라이선스 검증 상태: **미검증**. 공식 기관이 공개한 자료이지만 정확한 재배포 조건이
  명시되어 있지 않아, MathJK와 동일하게 보수적으로 `usageMode: REFERENCE_ONLY`를 유지한다.

## 현재 허용 용도

- `usageMode: REFERENCE_ONLY` — 개발팀이 CSAT 관련도/난이도 교정(calibration)의 증거로
  참고하는 용도로만 사용한다.

## 금지된 프로덕션 용도 (라이선스 검증 전까지 전부 금지)

- 문항 원문을 그대로 복사해 서비스에 노출하는 것
- 숫자·기호만 바꾼 경미한 변형으로 신규 문제를 생성하는 것
- 이 자료(원문/페이지 이미지)를 OpenAI/Anthropic 등 외부 AI API로 전송하는 것
  (`apps/api/src/infrastructure/ai/`의 `LLMAdapter`는 이 파이프라인 어디에서도 사용하지 않는다)
- 이 자료를 AI 모델 파인튜닝/임베딩 데이터로 사용하는 것
