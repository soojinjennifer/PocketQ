## 사용 원칙

- Figma의 색상, 글꼴, 간격, 모서리, 그림자, 스타일 값을 기준으로 한다.
- Math_based on iOS 26 Design System.zip 은 디자인 시스템 기본 구조 파일이고, 여기서 Math Material — Button · Card · Tabs, Math Bold-3D — Elevation, Math Bold-3D — In Use 을 중심으로 참고 한다. 
- iPad 수학 튜터 앱 디자인.ZIP은 구조와 콘텐츠를 파악하는 참고 자료로만 사용한다.
- Figma와 ZIP 디자인이 다르면 Figma를 우선한다.
- 임의의 디자인 값은 추가하지 않는다.
